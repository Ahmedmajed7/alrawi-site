# Al Rawi Smart Home — website

Client: Al Rawi Smart Home (alrawioman.com), Omani smart-home integrator, offices in Muscat and Riyadh.
Bilingual (Arabic default, English) static marketing + product site. Landing = tap-through **film** of a walled villa in an Omani neighbourhood at golden hour, the Hajar range filling the band behind, seen from the far pavement across the street (the key visual, with "SMART LIVING" as HTML top-start; no logo in the scene since 28 Sep 2026, the brand stays in the HTML header) (hero loop → gate → the front door opens → the control panel on the first wall on the right → four more devices → backwards out of the door, which closes in front of the lens onto the smart lock), plain `<video>` so it is smooth on old PCs. The per-product 3D viewer was removed at the client's request (29 Sep 2026); product pages show photos. Goal set by the client (28 Sep 2026): photoreal, never "graphic or plastic"; each device's specs open as an Iron Man-style holographic HUD. Placeholder clips are recorded from the 3D villa; the final clips are AI video (see `docs/film.md`). Design: luxury light cinematic (paper/stone/brass; type Marcellus + Jost, Arabic El Messiri + Cairo, all via `--f-*` tokens). No backend.

## Stack
- Astro 7 (static output, `trailingSlash: 'always'`), vanilla CSS with tokens (`src/styles/01-tokens.css`), self-hosted fonts (Marcellus, Jost, El Messiri, Cairo via @fontsource).
- Film player `src/scripts/film/player.ts` driven by `src/data/film.json` (written by `npm run film:encode`). The three.js walkthrough in `src/scripts/three/house/` (live with `?live3d`; used to record the film) (walkthrough.ts orchestrates; loader/materials/renderer/environment/street/vegetation/door/court/interior (+ interior-*.ts)/camera-rig/devices/slideshow/author; `court.ts` rebuilds the entrance court in clean geometry where the AI shell was cut away: `villa.json` `court-*` cuts) driven by `src/data/house.json` (poses, stops) and `src/data/villa.json` (model cuts + floor plan); product viewer `src/scripts/three/product-viewer.ts`; procedural device models `src/scripts/three/procedural/index.ts`; GSAP; Lenis (desktop only).
- Deploy: Cloudflare Pages, output `dist/`. Headers in `public/_headers`.

## Commands
- `npm run dev` / `npm run build` / `npm run preview` / `npm run check`
- `npm run extract` — pull text + images from the catalogue PDF into `scripts/_cache/` (git-ignored)
- `python3 scripts/make-webp.py` — convert hand-picked catalogue images into `public/img/`
- `npm run fetch-nalite` — download supplier gallery photos listed in `products.json` `sourceImages`
- `npm run villa:build` / `npm run villa:dev` — cut, simplify and compress the Tripo villa (`assets/house/villa-tripo.glb`) into `public/models/villa-<hash>.glb` (+ lite); see `docs/house-model.md` for the probe/cut loop
- `npm run sky:build` — bake the Poly Haven golden-hour sky HDRI (`evening_road_01_puresky`; `--preview --src=<id>` bakes a candidate into `dist/` and prints the `?skyimg=…` flags to try it live) into `public/textures/sky/sky-<hash>.webp` and set `house.json` `sky.image`, `skyYaw`, `sun.dir` (`--src=`, `--azimuth=`)
- `node scripts/build-env-textures.mjs` — convert the cached Poly Haven exterior sets (render wall, dense sand, lawn AO/roughness) into `public/textures/env/`
- `node scripts/fetch-interior-textures.mjs` — download the interior PBR sets (linen, velvet, walnut veneer, limewash plaster; Poly Haven CC0) into `public/textures/interior/`
- `npm run trees:build` — simplify + compress the photoscanned sidr tree into `public/models/tree-<hash>.glb` and set `house.json` `plants`
- `node scripts/build-props.mjs [--only=kind,…] [--wire]` — photoscanned Poly Haven props (shrubs, potted plants, planters, armchair, coffee table, vases, street lamps) → `public/models/prop-<kind>-<hash>.glb`; `--wire` writes `house.json` `props` (the scene falls back to code-built pieces for any missing kind)
- `npm run film:record` — record the 3D walkthrough frame-exact into `assets/film/source/` + keyframes (needs `npm run dev`; `SITE=` to point at it; `--check` prints a motion/jerk metric per clip and PASS/FAIL, `--only=`, `--size=`, `--blur=K` motion blur for the moves (6 at 60 fps; recording takes about K times longer), `--fps=` / `--hero-fps=` (defaults 60 / 30); `--size=2560x1440` records the 2K film the top rung is cut from (the page renders at `?pr=1.5`, the same 3840-wide buffer 1080p is averaged down from); record one `--only=<clip>` per process under `caffeinate`, and never run another headless render meanwhile (two record renders at once can come back solid magenta))
- `npm run terrain:build` — the real Hajar behind the villa from AWS Terrain Tiles (house.json `terrain` viewpoint; `--preview --cands="lat,lon,bearing;…"` compares viewpoints) → `public/models/terrain-<hash>.bin` (+ lite); re-run after `sky:build`
- `npm run serve` — serve `dist/` like Cloudflare Pages (`_headers`, brotli, ranges) on :4331; judge load speed there, not on `astro preview`
- `npm run film:encode` — encode `assets/film/clips/<id>` (AI) or the placeholders to `public/film/`, write `src/data/film.json`, posters and `og.jpg` It first builds a master per clip in `scripts/_cache/film-master/` (27 Sep): `assets/film/steady.json` boxes held with a temporal median (z-fighting faces), time resampled with an even shutter at `assets/film/speed.json` speeds (multiples of 0.25; now all 1: the rig plans every move at its final pace; a move recorded with `--blur` at speed 1 is kept frame for frame, blending on top of real motion blur doubles edges), deflicker + temporal denoise, then the grade (`LOOK`: clarity, deeper mids, sharpen); CRF 19, the hero as one GOP. Output is a ladder per clip (film.json `rungs`): 720p / 1080p / 1440p in H.264 + HEVC (2K is the top at the client's request; each file kept under Pages' 25 MB), only rungs the source is tall enough for; the player (`chooseRung` in `film/player.ts`) picks the rung that fills the screen's device pixels, capped for phones (1080p), low memory/CPU/slow lines, confirmed with `navigator.mediaCapabilities` (smooth, and power-efficient above 1080p), steps down for the moves when the hero's measured download says the line is slower, and for the rest of the visit if a clip drops > 8 % of its frames. See docs/film.md "Published look". The recorder renders without grain or lens fringing.
- `npm run shoot:stops` — stills of the live 3D (only used by `?live3d`'s no-WebGL fallback)
- `node scripts/shoot.mjs out.png URL [w h] [waitMs] [selector] [jsBefore]` — headless screenshot; walkthrough dev flags (all switch the landing to live 3D): `?live3d`, `?stop=N`, `?cam=x,y,z&look=x,y,z[&inside=1]`, `?clip=<y>`/`?cx=`/`?cz=` (cutaways), `?hide=shell,interior,door,gate,env`, `?env=sky,mountains,street,grass,trees,oasis,apron,logo,clouds,birds` (skip), `?model=/models/villa-dev.glb`, `?ray=x,y,z,tx,ty,tz;…`, `?author`, `?tier=low|high|off`, `?slides=1`, `?record` (film-quality renderer at 2x: 4K sun shadows with the villa's PCSS filter on fixed taps, 32-sample AO, depth of field; `?nodof` turns the lens off, `?nograde` the grade; when shooting stills with `?record` run `window.__rec.begin()` as the jsBefore so the frame renders)

- Pages (29 Sep 2026 redesign): content and its order come ONLY from the live WordPress site alrawioman.com (Home, About, Smart Control, Contact); Arabic is a faithful translation; never add copy. Nav = Home · About · Smart Control · Products · Contact (`/services/` redirects to `/about/#services` via `public/_redirects`). Home order: film → hand-off (`#philosophy`, the live slider lines; the film player scrolls there) → About us → Our Services → Why Choose Us → How It Works → the two FAQ questions → footer.
- Page design (v3, 30 Sep 2026, client: "remove the Dartz background elements", chose "warm quiet luxury"; NO mountains/ridges, NO Rasa arches, NO film stills or screenshots in the pages, NO drafting grids, constellations, target rings, reticles, HUD brackets, scans, § coordinates or pointer effects): ivory and stone bands (`band--paper`/`band--mist` = `--page`/`--mist`) with a very fine static paper grain (`--grain`, an inline feTurbulence tile), generous space, thin brass hairlines (`--hair`, section dividers, `.kicker` small-caps labels, the short rule under `SecHead` titles), headings in the display serif (`--f-head` = Marcellus, El Messiri in Arabic), fine Jost-light numerals in brass, card faces `--card` with soft warm shadows (`--shadow-soft`/`--shadow-lift`), round brass-hairline icon rings, footer and drawer warm espresso (`--espresso`) with brass; motion is only `[data-reveal]` fades, the ServiceArt brass line drawings drawing in once and the home process rail. Parts: `PageHero` (crumbs, serif title, brass rule, faint golden-hour light), `SecHead` (kicker, title, lead), `Stat` (count-up figure), ledger rows `.row` (+ `ServiceArt`), `magnetic` buttons. The home hero after the film (`#philosophy`, `[data-hero2]`: beams, logo mark, aurora, `.grid-lit`, `canvas[data-net="logo"]` via `motion/net.ts` + `motion/home.ts`) was approved separately and keeps its v2 look (its own paper, ink hairlines and Jost/Cairo pinned on `.band.hero2`). Styles `03-layout.css`, `07-sections.css`, `13-pages.css`.
- Content: `src/data/products.json` (catalogue, bilingual), `categories.json`, `services.json` (the live site's six services), `controls.json` (Smart Control systems + catalogue links), `site.json` (offices, phones, email, Instagram, partner brands, WhatsApp, form key) — offices/phones/email as on the live site.
- UI strings: `src/i18n/ar.json`, `en.json`; helpers in `src/i18n/utils.ts` (`useT`, `l`, `localePath`, `altLocalePath`).
- Routes: `src/pages/[lang]/...` (index, about, smart-control, contact, products/…) generated for `ar` and `en`; root `/` redirects by saved choice then browser language.
- 3D devices: set `"model": true` on a product and drop `public/models/<slug>.glb` (see `docs/3d-models.md`); otherwise `shape` + `shapeParams` pick a procedural recipe (panel, puck, disc, switch, lock, rail, box, orb), each modelled after the catalogue photo of that device. The walkthrough mounts the same recipes at real size (`house.json` → `device.scale` in metres, mounting face = recipe −Z, `device.params` overrides e.g. `back:false`, `cloth:false`, `tilt:false`, `can:false`). The mount face is the model's −Z extreme, so anything meant to sit inside the wall (back boxes, cans) must be opt-out for the walkthrough.
- Logo paths: `src/data/logo.ts` (used by `Logo.astro`; the 3D monument over the villa was removed at the client's request, 28 Sep 2026).
- Walkthrough stops/camera: `src/data/house.json` (metres, Y-up, origin = front-door threshold, exterior +Z / interior −Z, interior floor y 0.55, ceiling 3.1). The lock stop mounts on the door leaf (`device.mount: "door"`). Devices sit at real heights (panel 1.45 m, switch 1.30 m above the floor): the control panel on the pier's stone-clad west face (surface x 1.51), the first wall on the right as the front door opens (client's request); the switch on the main room's east wall. Every recipe carries a child named `hotspot` where the film's leader line lands. The six film devices have their own recipe files in `procedural/devices/` (panel, switch, lock, speaker, detector, curtain; shared helpers in `procedural/kit.ts`), each dimensioned in millimetres after the catalogue unit; they return null for parameter sets that mean another product, which then falls back to the generic recipe in `procedural/index.ts`.
- Look: AgX tone mapping + a film grade pass (`house/grade.ts`: split tone, contrast, vignette, grain; `?nograde`), room-environment reflections indoors (`env.roomEnv`), sky PMREM outdoors, drifting cloud shadows on every sunlit surface (`cloudShadow()` in `house/wind.ts`, a circular drift that seams); the photographed sky's own clouds (no painted veils), the real terrain in the background pass (`house/terrain.ts`, its own long-range camera). The sun's shadows use the villa's own filter (`installShadowFilter` in `house/renderer.ts`: contact-hardening PCSS with receiver-plane bias, fixed taps when recording; `?shadows=stock` for three's PCF, `?vtaps=search,taps,spot`); the shadow map zooms with the camera's distance from the plot. Interior surfaces: `house/interior-surface.ts` (world-space limewash, room shading, analytic sun apertures), a baked irradiance probe grid for bounce light (`house/interior-gi.ts`, 10-20 s at warm-up; `?gi=0`). The hero lens is `exterior.fov` (the tour runs at 50), the mountain rings `sky.mountains`, the optional baked lightmap `shell.lightMap` (docs/house-model.md). Fog reach, mountain haze and the sky fill breathe by a few percent (`?env=breathe` skips it). Everything that moves (wind — one direction, `house.json` `wind.dir`, every plant bends downwind about its base, fronds pivot at their roots — birds, flames, lantern flicker, sheers, smoke, dust, the hero lens breathe) reads the shared `WORLD_TIME` clock with rates that are multiples of 0.5 rad/s so the 4π s hero loop seams.
- Camera (`house/camera-rig.ts`): every move is planned in full the moment it starts (`planMove`, pure: the offline simulator runs the same code). Body: a centripetal Catmull-Rom through the via points, resampled by arc length and smoothed, paced by a minimum-jerk profile over a cruise-speed field (`PACE`: 3.7 m/s indoors, 2.9 through the front door and the cased opening, 11 over the lawn; `RAMP` 0.75 s in, 0.95 s out). Head: a planned yaw/pitch track through the start pose, optional `aims` and the final look, tied to the body's progress, so both start and stop on the same frame exactly on the authored pose (no spring, no lag, no settle). `LIMITS` stretch a move until yaw ≤ 70°/s and 140°/s², pitch ≤ 45°/s and 100°/s², acceleration ≤ 8 m/s². `tourMoves()` builds the tour from house.json: enter (street → gate → door → the panel), goTo (stop to stop; back = the same path reversed), leave (backwards out of the front door; the door closes in front of the lens onto the lock), reenter, outro. The tour takes about 27 s. Keep via points ≥ 0.5 m from surfaces and at eye level indoors (2.05 m absolute).
- Film overlay: at each device a holographic HUD in the Iron Man / lab-hologram language (client's request): no marker on the device and no leader line (removed at the client's request, 29 Sep 2026); a transparent hologram-glass panel (a light tint over a backdrop blur, luminous edges, text with a dark halo) beside the device, unfolding from the edge that faces it, with the room and category, the name decoded in, the catalogue `blurb`, 4–6 spec rows from `products.json` `specs` (bilingual, only facts from the catalogue or the product data) and one animated widget per device (climate dial, dimmer bars, curtain travel, spectrum, air-quality sweep, fingerprint scan). Placer `film/callout.ts` (shared by the film player and the live 3D, which projects the device's `hotspot` node each frame; the intro plays once per stop, later calls only reposition; the panel keeps clear of the device's box published by `film/device-live.ts` via `film/hud.ts`), decode/parallax `film/hud.ts`, SVG paths `film/hud-geometry.ts`, styles `styles/11-hud.css`, strings `walk.hud.*`; RTL-aware (the panel's side is physical), docks to the bottom on portrait phones, a plain fade under `prefers-reduced-motion`. Under `?live3d` only: pointer parallax in the hero and OrbitControls around the villa after the outro (both off when recording). Live devices: on each paused device real HTML is pinned onto its recorded features (film.json `features`: quads like the panel's `screen`, points like `led_0`; named nodes in the procedural recipes) by `film/device-live.ts` + `film/homography.ts` — the panel's screen is a working UI (`components/PanelScreen.astro`, same layout as the painted texture in `data/panel-ui.ts`), the switch, lock, smoke detector, speaker and curtain motor get small live touches. The panel's live screen also follows the moving film: the recorder stores its screen corners per frame when it is fully in view and unoccluded (`__rec.track`), the encoder publishes them as `public/film/track-<id>-<hash>.json` (film.json `track`), and the player pins the HTML to each decoded frame (`requestVideoFrameCallback`). One `npm run film:record` records the tour moves at 60 fps and the hero loop at 30 (defaults) with a 0.3 s hold after each move; `--blur=K` gives the moves a K-sample 180° shutter (`?shutter=K`, `__rec.step`); the encoder keeps each clip's rate. Devices: satin/brushed surface grain, soft contact shadows behind every mounted device (`house/devices.ts`), the dark graphite switch with backlit bulb icons (products.json `finish: graphite`).

## Conventions
- RTL first: logical CSS properties only; `.icon-dir` mirrors directional icons under `[dir=rtl]`.
- Every text shown to users comes from `i18n/*.json` or the bilingual data files, never hard-coded in components (except the 404 page).
- `[data-reveal]` for scroll reveals; `data-stagger` on the parent staggers children.
- Performance tiers (`perfTier()` in `three/common.ts`): `off` shows photo/poster, `low` disables bloom/shadows/grass/transmission, `high` gets everything.
- The whole hero is tappable (only `a`/`button` catch the pointer).
- `/film/*` and `/models/*` are cached immutable: published files always carry a content hash.
